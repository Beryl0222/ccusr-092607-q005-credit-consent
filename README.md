# 支付信贷授权穿透账

把支付意图、优惠条件、界面版本、信贷要约、综合融资成本、适当性输入、授权动作、合同参与方、放款、收费、还款与催收通知连接成一条**不可覆盖的链路**，解决"为领一次立减点付款却生成月付账单、事后无法证明页面展示了什么、谁完成了负担能力判断"的问题。

## 目录

- `contracts/domain.schema.json`：事件信封、21 类事件、载荷必填与枚举约定。
- `data/sample.json`：可直接校验的联调样例。
- `src/credit_consent/`
  - `contracts.py`：基础契约校验（不修改输入）。
  - `ledger.py`：哈希链只追加账本、业务键幂等、JSONL 持久化与重放验链。
  - `clock.py`：可控时钟（犹豫期、账单、逾期、异议期）。
  - `domain.py`：领域服务与状态机（双决定、适当性治理、重确认、撤销、冻结、原子扣款）。
  - `readmodel.py`：消费者解释、审计历史还原、放款方最小化视图。
  - `cli.py`：命令行契约校验。
- `tests/`：信封、账本哈希链与篡改检测、领域不变量、并发扣款、重启恢复、视图测试（35 个）。
- `docs/domain.md`：领域对象、事件语义与不变量。

## 核心规则

- 支付确认与信贷同意是**两个独立的显式决定**；默认勾选、预填、优惠都不能代替授权。
- 营销配置人员**无权批准**适当性规则；放款方只能看到履责所需数据（适当性原始输入仅留哈希）。
- 合同主体或费率变化必须**重新确认**，旧同意立即失效。
- 撤销未使用授信：释放额度但**保留全部历史证据**，撤销后不得放款。
- 网络重试不重复签约/放款/扣款；同一业务键出现不同界面指纹或金额**立即冻结**案件。
- 多个扣款请求争用同一可用余额时在临界区内**原子裁决**。
- 时钟可控、阶段由事件流重建，**重启不重置阶段**。

## 样例校验

```bash
PYTHONPATH=src python3 -m credit_consent.cli contracts/domain.schema.json data/sample.json
```

样例有效时输出 `valid`；发现问题时逐行给出字段、代码和中文说明，并返回非零状态。
